# ☕ Brew Bucket Coffee

موقع صفحة واحدة (Single Page Website) لكافيه **Brew Bucket Coffee** في Oak Lawn — تصميم عصري فاخر ومتجاوب بالكامل مع الموبايل والتابلت.

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| HTML5 | هيكلة الصفحة بعناصر دلالية (Semantic) |
| Tailwind CSS (CDN) | التنسيقات بالكامل بدون أي تثبيت |
| Vanilla JavaScript | قائمة الموبايل + أنيميشن الظهور عند التمرير |
| Node.js (اختياري) | سيرفر محلي بسيط لتشغيل الموقع |

## 📄 أقسام الموقع (9 أقسام)

1. شريط تنقل ثابت مع قائمة هامبرغر للموبايل
2. قسم Hero بصورة خلفية معتمة وأيقونات اجتماعية
3. Signature Picks — 3 كروت مشروبات مميزة
4. About — قصة البراند
5. Menu — فئتان مع خطوط منقطة تربط الاسم بالسعر
6. Gallery — شبكة 6 صور
7. Reviews — تقييمات العملاء مع 5 نجوم
8. Contact — عنوان + هاتف + خريطة جوجل حية
9. Footer — روابط سريعة ومواعيد العمل

## 🚀 التشغيل

### الطريقة 1: افتح الملف مباشرة
افتح `index.html` في المتصفح — الموقع يعمل فوراً بدون أي إعدادات.

### الطريقة 2: سيرفر محلي (موصى به)
```bash
node server.js
```
ثم افتح: http://localhost:8000

## 📁 هيكل المشروع

```
brew-bucket-coffee/
├── index.html   # الموقع كامل (HTML + CSS + JS بكومنتات شرح مفصلة)
├── server.js    # سيرفر Node.js محلي مع شرح لكل سطر
└── README.md    # هذا الملف
```
